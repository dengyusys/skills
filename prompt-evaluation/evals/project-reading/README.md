# project-reading：代码阅读指导提示词（项目级三维度）

## 测什么

同一套 code-reading 提示词（v1-v6）换任务类型的泛化测试，材料摘自 ai-steward-a 项目文档（只读）：

1. **项目设计**：这项目是干嘛的、为什么这么设计（模块表 + 安全主线）
2. **项目架构**：组成部分、连接方式、一次记录从输入到落库的数据流（材料不含图，逼模型自己画）
3. **代码可读性评价**：先结论后展开、引用具体证据
