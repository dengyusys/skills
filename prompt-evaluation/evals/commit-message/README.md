# commit-message：write-git-commit-message 提示词（入门示例）

系统的第一个示例测评，也是验证评测台本身的最小用例。

## 变体

| 文件 | 标签 | 说明 |
|------|------|------|
| prompts/v1.txt | v1 基础版 | 技能核心规则的精简版 |
| prompts/v2.txt | v2 收紧版 | v1 + 50 字符上限 + 多目的建议拆分 |

## 用例

1. 修复类改动（中文仓库）：conventional 格式 + 描述结果不罗列文件
2. 英文项目新功能：格式 + 英文书写
3. 互不相关的多处改动：应建议拆分提交而不是给单一信息
